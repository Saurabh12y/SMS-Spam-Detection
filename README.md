
# SMS Spam Detection System

## Project Description
A machine learning application that detects whether an SMS message is Spam or Ham.

## Objective
To identify unwanted SMS messages using machine learning techniques.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit
- TF-IDF
- Multinomial Naive Bayes

## Algorithm
Multinomial Naive Bayes Classifier.

## Features
- SMS classification
- Spam detection
- Prediction confidence
- Model performance dashboard
- Confusion matrix
- Message history

## How to Run

1. Install dependencies:
   pip install -r requirements.txt

2. Train the model:
   python train_model.py

3. Start the application:
   streamlit run app.py

## Project Type
College Machine Learning Project.
